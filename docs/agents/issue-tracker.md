# Issue tracker configuration

- Tracker: GitHub Issues at https://github.com/acone87-arch/Fixit/issues
- Canonical repository: `acone87-arch/Fixit`; default base branch `main`.
- Approved work can be represented by a GitHub Issue with objective, scope, acceptance criteria, affected roles, dependencies, migration impact, and exact test evidence.
- PRs are implementation/review records, not an automatic intake queue.
- Do not create, label, close or reassign issues without user authorization for that action.
- Avoid inventing triage labels. No `triage` label map is configured yet; configure with the upstream setup skill if adopting triage.
- Use concise, testable tracer-bullet tickets. Track blockers in issue bodies or GitHub's native relationships when available.
- Do not assume a merged PR is deploy-safe: `main` triggers production deploy.

Conventions may be edited without changing the underlying source code.
